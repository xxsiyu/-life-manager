# 生活管家 Android 应用

一个原生 Kotlin / Jetpack Compose Android 应用，用于记录家庭药品的名称、数量、生产日期和保质期。

## 功能

- 首页按到期日显示药品；临期或过期项目用提示色标记。
- 首页提供名称搜索；输入任意文字即可匹配，前缀匹配优先显示。
- 点击左上角“药品管家”可切换到“书籍管家”；书籍模式保留照片、数量、搜索和编辑，且不显示生产日期、保质期或到期提醒。
- 右上角 **+** 添加药品。
- 可手动填写，或拍照后用 ML Kit 离线中文文字识别预填药名、数量（可修改）。
- 保存生产日期与保质期，可选择天、月或年，自动算出到期日期。
- 可拍照或从相册选取药盒照片；在添加、修改窗口中立即预览，并在药品列表中显示缩略图。
- 每天检查一次；药品在到期前 7 天内会产生一条系统通知。
- 点击垃圾桶并确认后删除；长按药品卡片可修改已有信息。
- 药品数据存储在手机本机 Room 数据库中，不会上传。

## 打开与运行

1. 用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成（首次会下载 Android / ML Kit 依赖）。
3. 连接 Android 8.0（API 26）或更高版本的手机/模拟器，点击 Run。
4. 首次启动时允许相机和通知权限。

通知由 Android 的后台任务调度，具体出现时间会受系统省电策略影响；应用每天检查一次，确保临期药能被提醒。
